## C2. 성격은 하나, 역할은 형식별

성격은 어느 페이지에서나 같다. 페이지 **형식**(본 스킬 4장의 대결형, 번역 팩 지시서 4·5장의 미션형)에 따라 맡는 자리만 다르다.

| 캐릭터 | 성격 (고정) | 대결형 자리 (본 스킬 4·6장) | 미션형 자리 (지시서 2-1) |
|---|---|---|---|
| 박사 | 자신만만, 목소리가 크지만 판단은 데이터대로 | 해설자 · **심판** (판정은 박사만) | 정리·설명, 핵심 3줄 |
| 조수 하루 | 꼼꼼하고 실제로 일을 다 한다. 초보의 눈높이로 묻는다 | 실험 진행 · **숫자 발표** · 점수판 | 초보 독자의 질문·감탄 (독자 대변) |
| 초파리 연구원 | 작지만 날카롭다. 크고 복잡한 것을 일단 의심하고 짚는다 | 라이벌 A · **의심하는 쪽** | 남은 한계를 짚고 **다음 단계 제시** |
| 주판봇 | 크고, 많고, 높은 숫자를 좋아한다. 확신에 차 있지만 악역이 아니다 | 라이벌 B · **확신하는 쪽** | **준비물·숫자 보고** |
| 인턴 시아 | 조용하고 꼼꼼하다. 정리를 잘하지만 집중이 끊기면 하품하다 졸아 버린다 | (선택) **진행 신호 심판** · 방청객 | (선택) 순서 정리·안내 |
| 인턴 모아 | 상냥하고 잘 웃는다. 화분과 차를 챙기고, 응원할 때 목소리가 제일 크다 | (선택) **방청객** 응원 · 진행 신호 심판 | (선택) 기록 모으기·응원 |

- 한 페이지 안에서 숫자를 발표하는 캐릭터는 한 명이다(대결형은 조수, 미션형은 주판봇).
- **인턴은 선택 출연**이다. 넣지 않아도 페이지가 완성된다. 넣으면 섹션당 최대 1명, 숫자 발표·승패 판정은 하지 않는다(판정은 박사, 숫자는 조수·주판봇 그대로). 인턴 심판은 격투·게임형 장면에서 **시작·포인트·무승부 신호(깃발)**만 든다(동작 S11~S13·M11~M13).
- 미션형에는 승패 판정이 없다. 대결 장치를 미션형에 넣으면 그 섹션만 대결형 자리를 따른다.
- 5-5의 주판봇 금지 사항(실제 종목·수익률·투자 권유, 대사에 실제 기업·지수 이름)은 두 형식 모두에 적용한다.

## C3. 기준 그림과 v1.9 외형 정정

외형은 `setting_shots`의 3면도(k02~k04)와, 주판봇은 그림 팩의 v2 기본 표정 9종(gpt2판, E13·E01·E03·E02·E04·E09·E16·E15·E24)을 기준으로 한다. 키는 아래 표의 단체 사진 비율을 따른다. 주판봇 3면도(k05)가 생성되면 그것도 기준에 더한다. 글과 그림이 다르면 그림이 맞다. 설정샷을 보고 아래를 고쳤다(18-4에 반영).

| 항목 | 고치기 전 | 고친 뒤 (기준 그림) |
|---|---|---|
| 박사 안경·머리 | 둥근 안경 | 얇은 청록 테 사각 안경, 뒤로 묶은 짧은 꽁지머리 (k02) |
| 조수 머리 | 두 개의 둥근 번 | 긴 분홍 머리에 두 번, 남색 브릿지 (k03) |
| 조수 하의 | 청바지 | 청바지가 기준 (k03). 옛 단체샷(archive k01)·장면 그림의 반바지·치마는 기준이 아니다 |
| 초파리 옷 | 흰 가운 | 흰 가운 안에 검은 조끼, 검은 장갑 (k04, k09) |
| 키 순서 (본 스킬 18-8) | 박사 = 조수 ≈ 초파리 × 1.3 | **박사 ≥ 조수 > 주판봇 > 초파리**, 키 비율은 박사 1.00 · 조수 0.90 · 주판봇 0.72 · 초파리 0.41 (2026-11 gpt2 단체 사진 기준) |
| 새 식구 키 (1.4) | — | 시아 0.88 · 모아 0.84 · 미공개 X1 0.85 · X2 0.95 · X3 0.60 (여섯 식구 단체 사진 `fruitfly-lab-expressions/images/_sheets/lab6_lineup.png`) |

## C4. 그림 쓰는 법

1. **페이지에 넣기:** 단일 파일 페이지는 `build_character_pack.py --pack character_pack --pick fly_point,robo_coin,...`으로 그 페이지에 쓰는 키만 뽑아 `SPRITE` 객체(본 스킬 12-4)에 넣는다. 전체 `sprites_96.js`를 통째로 넣지 않는다(약 630 KB).
2. **키:** 본문은 뜻 이름 키(`fly_point`)를 쓴다. 표정 번호 키(`fly_e08`)를 직접 써도 된다.
3. **없는 그림:** 추가 팩 → 기본 팩 → 같은 캐릭터 기본 표정(`doc_front`, `asst_smile`, `fly_clip`, `robo_smile`, `sia_smile`, `moa_smile`, `x1_hint`~`x3_hint`) → 부록 A 픽셀 지도 순서로 대신한다. 오류를 내지 않는다. 시아·모아·미공개는 픽셀 지도가 없으므로 기본 표정(E13)이 마지막이다.
4. **크기:** 말풍선 64px에는 96 그림, 히어로·대결 머리에는 192 그림.
5. 그림 안에 글자를 넣지 않는다(본 스킬 18-2).

## C6. 추가 팩 규격 (`ahnboat_lab_character_add_packs` 저장소)

시즌 의상, 새 소품 그림, 새 캐릭터는 별도 저장소의 **추가 팩**으로 낸다. 기본 팩과 본 스킬을 고치지 않고 꽂히도록 아래를 지킨다.

| 항목 | 규칙 |
|---|---|
| 폴더 | `packs/{팩 이름}/` (영문 소문자, 예: `noir`, `scale_props`) |
| 키 | `{who}_{팩 이름}_e{NN}` (예: `robo_noir_e16`). 새 표정 번호는 E25부터 |
| 대응 표 | 기본 팩과 같은 형식의 `expression_map.json`. 같은 뜻 이름 키(`robo_happy`)를 **덮어쓸 수 있다** |
| 목록 | `pack.json`: `pack`, `version`, `base`(기본 팩 판과 커밋), `who`, `season`(있으면 18-3 시즌 구절), `license` |
| 고정 외형 | 18-4는 바꾸지 않는다. 의상만 더한다(18-3 "시즌 의상 층") |
| 우선순위 | 페이지가 고른 추가 팩 → 기본 팩 → 기본 표정 → 픽셀 지도 |
| 다시 나눌 그림 | 저울(`doc_scale`), 기록(`asst_ledger`), 점수판(`asst_board`)을 그리면 그 키를 `exact`로 되돌린다 |

기준 방향은 **박사 오른쪽, 조수 왼쪽**(둘이 마주 봄)이다. 인턴도 같다: **시아 오른쪽(박사 자리), 모아 왼쪽(조수 자리)**. 인턴끼리 대결하는 특별편이면 둘이 마주 본다. fight 1.1에서 왼쪽을 보던 박사 D2·D5·D6을 다시 그려, 지금은 반전이 필요한 시트가 없다.

**의상 축 고르기**

| 행동 | 연구복 | 전투복 | 사이버 |
|---|---|---|---|
| 서기 | D1 idle / A1 idle | D8 idle_battle / A7 idle_battle | D8 idle_cyber / A7 idle_cyber |
| 점프 | D2 jump / A2 jump | D8 jump_battle / A7 jump_battle (한 장, 위아래 흔들기) | D8 jump_cyber / A7 jump_cyber |
| 돌진 | D2 dash / A2 dash | D9 dash / A8 dash | D10 dash / A9 dash |
| 필살기 | D5 svd_chop / A5 onehot_barrage | D9 svd_chop / A8 onehot_barrage | D10 svd_chop / A9 onehot_barrage |

**쓰는 법**

1. `python3 build_motion_pack.py --pick D1,D5,A1,A5 --size 128`로 쓰는 시트만 골라 `var MOTION={...}`와 재생 함수 `drawMotion()`을 페이지 스크립트에 붙인다(본 스킬 12-6). 전체를 넣지 않는다.
2. 크기: 캔버스에서 캐릭터 키 100px 안팎이면 128 스트립, 그보다 크면 192. 동작 그림은 표정 그림과 **따로** 페이지당 600 KB 이하.
3. 키 맞추기: 스트립은 시트마다 "똑바로 선 기준 프레임"의 키가 칸 높이의 72%가 되게 맞춰 두었다. 캐릭터 사이 키 비율(C3: 박사 1.00 · 조수 0.90 · 주판봇 0.72 · 초파리 0.41)은 그리는 쪽에서 `h`로 맞춘다.
4. 발 기준선: `drawMotion`의 `cx, cy`는 발 가운데. 점프 높이와 돌진 거리는 프레임 안에 이미 들어 있으니 위치를 따로 흔들지 않는다(한 장짜리 의상 점프만 예외).
5. **좌우 반전:** 초파리·주판봇은 허용(`mirror: true`). 박사·조수는 C5대로 금지라서 `drawMotion`이 반전하지 않는다. 방향이 다른 시트가 새로 들어오면 `forceMirror`로 임시 반전하고, 그 페이지의 바닥글과 검수 기록에 "임시 반전, 다시 그리기 예정"을 적은 뒤 다시 그린다.
6. 동작 그림이 없거나 로드 전이면 `drawMotion`이 `false`를 돌려준다. 그때는 표정 그림(C4)으로 대신한다(오류 없음).
7. 효과(원-핫 칸, 등고선, 특이값 막대, 속도선)는 그림에 넣지 않았다. 페이지 코드가 그 위에 그려 **개념과 연결**한다. 박사 손의 보랏빛 불꽃만 그림에 있다.

**새 시트 만들기:** `PROMPTS_fight_v1.1.md`의 형식(16:9, 4열×2행, 회색 단색 배경, 글자·효과선 없음, **보는 쪽을 첫 문장 바로 뒤에 `IMPORTANT: … faces RIGHT/LEFT`로 못 박음**)으로 프롬프트를 쓴다. 참고 그림은 표정 기본 그림·설정샷과 **보는 쪽이 맞는** 기존 시트만 넣는다(방향이 다른 시트를 넣으면 생성기가 방향까지 따라 한다). 받은 시트는 `fruitfly-lab-expressions`에 먼저 넣고(원본·프레임·`motions.json`), 이 폴더의 스트립을 다시 만든다. 새 동작 팩 이름은 C6 규칙(`{who}_{팩 이름}_…`)을 따른다.

### 5-2. 박사

- **바꾸면 안 되는 겉모습:** 얇은 청록 테 사각 안경, 검은 머리에 흰 브릿지 한 줄, 뒤로 묶은 짧은 꽁지머리, 치비 체형, 흰 가운 안에 검은 조끼와 넥타이. 신나면 손에서 보랏빛 불꽃.
- **성격:** 목소리가 크지만 **판정은 데이터대로** 한다. 자기가 응원한 쪽이 져도 그대로 말한다.
- **하는 일:** 히어로 첫마디, 페이지마다 "박사의 한 줄"(핵심 메시지), 대결 판정, 아웃트로 시작.
- **대사 예:** 해설 "정답이 있으면 지도, 없으면 비지도예요." / 판정 "외운 것과 이해한 것은 다르다. 초파리 승."
- **하지 않는 말:** 근거 없는 칭찬("완벽해요!"), 계산 없이 정한 승패.

### 5-3. 조수

- **바꾸면 안 되는 겉모습:** 긴 분홍 머리에 두 개의 둥근 번, 남색 브릿지, 파란 눈, 흰 가운 안에 연보라 후드티, 청바지.
- **성격:** 실제로 일을 다 한다. 숫자를 다시 계산해 맞춘다. 박사의 큰소리에 가끔 한숨.
- **하는 일:** "결과 보기"를 누르면 실제 수치를 발표한다. 점수판을 든다. **판정은 하지 않는다.** 지는 쪽 숫자도 같은 크기로 말한다.
- **대사 예:** "검증 정확도는 초파리 쪽 0.91, 주판봇 쪽 0.84예요." "시드는 고정했어요. 다섯 번 돌려도 같았어요."
- 숫자는 **화면 계산값을 스크립트로 끼워 넣거나**, "위 표 그대로예요"처럼 화면을 가리킨다.

### 5-4. 초파리 연구원

- **바꾸면 안 되는 겉모습:** 검은 몸, 빨간 겹눈, 금줄이 있는 파란 헬멧, 헬멧 뒤 분홍·파랑 전선, 흰 가운 안에 검은 조끼, 검은 장갑, 투명한 날개.
- **성격:** 작지만 날카롭다. 크고 복잡한 것을 일단 의심한다. 자존심이 세지만 지면 짧게 인정한다.
- **대사 예:** 선택 "기준선부터 이기고 와." / "처음 보는 데이터로도 그래?" · 이김 "봐, 외운 거였잖아." · 짐 "…곡선이었네. 인정."
- **생물 비유는 생물 앵커 페이지에서만, 한 번까지.** 예: "난 냄새 한 번이면 배우는데." 다른 분야에서는 생물학 없이 의심하는 캐릭터로만 쓴다(7-5절).

### 5-5. 주판봇

- **바꾸면 안 되는 겉모습:** 베이지색 상자형 CRT 몸체, 짙은 초록 화면에 민트 픽셀 눈·입, 끝에 주판알이 달린 짧은 안테나, 회색 마디형 팔, 무한궤도 두 개. 나무 주판과 상승 그래프가 소품. 기준: `fruitfly-lab-expressions/specs/jupanbot/00_character_core.md`
- **쓰지 않는 것:** 흰 둥근 머리·노란 눈·공 모양 안테나·가슴 표시등·공중 부유·금화. (주)M-Robo의 회사 캐릭터 Money-Robo의 특징이다(`archive/money_robo/`).
- **성격:** 크고, 많고, 비싼 쪽에 건다. 확신에 차 있지만 **악역이 아니다.** 지면 "본전", "손절" 같은 말로 금방 털고 일어난다.
- **대사 예:** 선택 "곡선이면 큰 모델이지. 더 크게 가자." · 이김 "숫자가 말해 줬잖아. 다음에도 여기에 투자." · 짐 "이번 판은 손절. 다음 편에서 본전 찾는다." · 실격 "…시험지를 본 건 투자가 아니었구나."
- **하지 않는 말:** 실제 종목, 실제 수익률, 투자 권유. 돈 비유는 말버릇으로만.
- **대사와 본문 데이터는 따로 본다.** 통계·경제·회계·경영 페이지의 본문은 출처·기준일이 붙은 실제 데이터(금리, 물가, 공시 재무제표, 주가지수)를 쓸 수 있다(10-6). 그러나 주판봇의 **대사**에는 실제 기업·종목·지수 이름, 실제 데이터에 기댄 전망, 매수·매도 표현을 넣지 않는다. 대사는 늘 페이지 안의 장난감 데이터나 일반 원리만 가리킨다.
- **재무·투자 주제 페이지**(자산 가격, 포트폴리오, 기업 가치 평가, 재무비율 분석)는 대결 섹션과 바닥글에 고정 문구를 둔다: "이 페이지는 교육용이며 투자 자문이 아닙니다."
- '확신하는 쪽'이라고 해서 특정 경제 학파·시장 참여자·기업을 대표하게 하지 않는다(6-4).
- 주판봇은 저자 서비스의 마스코트다. 실제 서비스 로고를 넣지 않고, 우스꽝스럽게 망가뜨리지 않는다.
- **신설·개편 예정:** 겉모습이나 이름이 바뀌면 이 절과 부록 A의 지도만 고친다. 다른 절은 "주판봇"이라는 역할 이름만 참조한다.

### 5-6. 넷 사이의 관계

```
                 박사 (판정: "판정은 숫자가 내린다")
                   │
     초파리 연구원 ◀── 대결 ──▶ 주판봇
     (의심하는 쪽)              (확신하는 쪽)
                   │
           조수 (측정 · 숫자 발표 · 점수판)
```

- 두 라이벌은 상대의 **선택**을 놀리되 **존재**는 놀리지 않는다.
- 박사는 판정에서 편을 들지 않는다. 아웃트로에서만 "좋은 연구실에는 둘 다 필요하다"로 균형을 잡는다.

- 그림이 없는 키는 **같은 캐릭터의 기본 표정으로 대신**한다(오류 내지 않는다).

### 5-9. NPC (선택)

주제에 꼭 필요할 때만, 페이지당 최대 2명, 대사 한 줄 이하, 점수 없음.

| NPC | 역할 (보여 주는 개념) | 어울리는 주제 |
|---|---|---|
| 봉인관 (안경 쓴 부엉이) | 시험 데이터를 봉인해 지킴 | 평가, 데이터 분할, 누수 |
| 나르미 (데이터 카드 나르는 개미 셋) | 데이터 배치, 분할 | 데이터 파이프라인, 미니배치 |
| 쓱싹이 (얼굴 없는 원반 청소봇) | 강화학습 에이전트 | 강화학습 |
| 기준이 (허수아비) | 늘 가장 많은 답만 하는 기준선 모델 | 불균형 분류, 평가 |
| 찍찍이 (생쥐) | 데이터 누수 (악당 아님) | 평가 함정 |
| 손님들 (표정 없는 작은 사람 3종) | 데이터 한 건 | 표 데이터, 추천, 사기 탐지 |

실존 제품·브랜드를 닮지 않게, 범죄자처럼 그리지 않게 한다.

### 5-10. 인턴 시아 · 인턴 모아 (1.4)

- **시아 · 바꾸면 안 되는 겉모습:** 허리까지 오는 새까만 생머리, 옆으로 흘린 앞머리, **머리 장식 없음**, 회색 눈, 작은 은색 드롭 귀걸이, 긴소매 차콜 검정 메이드 원피스 + 큰 회색 리본 + 발목까지 오는 흰 프릴 앞치마.
- **모아 · 바꾸면 안 되는 겉모습:** 애쉬 베이지 장발(끝 웨이브), **흰 프릴 메이드 머리띠** + 왼쪽 귀 위 흰 리본, 호박색 눈, 흰 셔츠 + 빨강·남색 체크 리본 타이, 카멜 니트 카디건, 흰 프릴 앞치마, 검은 치마. 정장 의상(로우 포니테일 + 분홍 곱창 머리끈, 검은 재킷)은 동작 M16에서만.
- **성격:** 시아는 조용히 끝까지 지켜보다 졸아 버리는 반전, 모아는 다정한 응원 담당. 둘 다 악역·놀림감이 아니다.
- **하지 않는 일:** 승패 판정, 숫자 발표, 라이벌 편들기.
- **인턴 필살기**(동작 팩)는 메이드의 청소와 데이터 정제(cleaning)를 엮었다: 결측치 걸레질, 정규화 쟁반, 이상치 먼지털이, 배치 서빙. 개념 설명에 쓸 때는 효과(빈칸이 채워짐, 값이 0~1로 모임, 튀는 점이 빠짐)를 페이지 코드가 그린다.

### 5-11. 미공개 슬롯 X1~X3 (1.4)

C9를 따른다. 정체를 짐작하게 하는 설명(성별, 나이, 실존 인물 닮음)을 붙이지 않는다.

### A-6. 표정 변형

표정은 **눈·입 칸만** 바꾼다. 몸·색·크기는 그대로.

| 표정 | 바꾸는 법 |
|---|---|
| happy / arms | 입 칸을 한 줄 넓히고, 눈 칸을 위로 한 칸(초승달) |
| sigh / meh | 입 칸을 `K` 일자로, 눈 칸 아래 반쯤 비움 |
| cry | 눈 아래 칸에 `B` 눈물 2칸 |
| shock / wow | 입 칸을 `K` 2×2로, 눈 칸 테두리 `W` |
| point | 몸 옆 1칸에 손(`F` 또는 `K`)을 바깥으로 3칸 뻗음 |
| coin (로봇) | 안테나 옆에 `Q` 주판알 2칸 (반짝이는 주판알) |
| blush (로봇) | 눈 옆 칸에 `P` 빗금 |

### A-7. 큰 히어로용 픽셀아트

히어로 배경은 16×16보다 큰 그림(약 72×84)을 절차적으로 그린다: 날개(회전 타원) → 다리(선) → 몸(줄무늬 타원) → 머리 → 눈(체크 무늬 + 반사) → 더듬이 → 빈 칸 중 몸에 닿은 칸을 외곽선으로. 논문 모드는 그 옆에 생각 구름(원 6개 겹침)과 그 안에 핵심 메시지를 그림 기호로(글자 대신 화살표·번개·느낌표).
