# 분야 팩 · 회계학 (`acct`)

## P1. 분야 신호어 (코어 2-0-1에 더함)

| 강한 신호 (3점) | 보통 신호 (1점) |
|---|---|
| 시산표, 결산, 발생주의, 수익·비용 대응, 매출원가, 재고자산 원가흐름, 감가상각누계액, 대손충당금, 이연법인세, 연결재무제표, 공정가치, 손상차손, 리스부채, 사용권자산, 원가배분, 손익분기점, 표준원가, 감사의견, 일반기업회계기준, US GAAP | 매출, 영업이익, 순이익, 재무비율 |

자주 함께 오는 보조 분야: 경영학(재무관리, 관리회계), 경제학(국민계정과의 비교), 통계학(감사 표본추출).

## P2. 짝 카드와 연결 상자

| 자리 | 이름 |
|---|---|
| 짝 카드 오른쪽 | "회계 처리로는" (분개, 계정, 재무제표 위치) |
| 파란 연결 상자 | "재무제표로 보면" — 이 거래가 재무상태표·손익계산서·현금흐름표 어디를 어떻게 바꾸는지 |
| 빨간 연결 상자 | "현장에 옮기면" (공통) — 회계 시스템 입력, 결산 일정, 증빙, 내부통제 |

## P3. 기본 앵커

**매출 기록·주판 앵커(C)는 회계 페이지의 주 앵커로 쓰지 않는다.** 거래 기록은 회계의 본론이라 비유가 되지 못한다(코어 7-2 시험 4번). 거래 기록은 본문 도식(T계정, 분개장)으로 직접 보여 주고, 비유는 거래 기록이 아닌 장면에서 고른다. 주판봇은 캐릭터로만 나온다.

| 주제 | 주 앵커 | 대응 예 | 초파리 캐릭터의 역할 |
|---|---|---|---|
| 회계 등식 (자산 = 부채 + 자본) | D 생활 | 시소: 한쪽에 물건, 다른 쪽에 "누구 돈으로 샀나" | 의심하는 쪽 ("한쪽만 움직일 수 있어?") |
| 복식부기 | D 생활 | 물건이 들어오면 반드시 어딘가에서 나간다: 이사할 때 상자 옮기기 | 진행 |
| 발생주의 vs 현금주의 | D 생활 | 미리 낸 1년치 헬스장 회비, 한 달씩 쓰는 것 | 의심하는 쪽 ("돈 낸 날이 쓴 날이야?") |
| 이익 vs 현금흐름 | D 생활 | 물탱크: 들어오는 물(현금 유입)과 수위(이익)는 다르다 / 외상 손님만 가득한 동네 빵집 | 의심하는 쪽 (주인공급) |
| 재고자산 원가흐름 | D 생활 | 우유 냉장고: 앞의 것부터 꺼내기(선입선출) vs 섞인 통에서 퍼내기(평균) | 의심하는 쪽 |
| 유형자산·감가상각 | D 생활 | 노트북을 5년 쓸 때 해마다 닳는 값 나누기 | 진행 |
| 수익인식 | D 생활 | 1년 구독 정기 배송: 상자가 갈 때마다 약속을 지킨다 | 의심하는 쪽 |
| 충당부채·우발부채 | D 생활 | 우산 대여점: 망가져 돌아올 우산을 미리 셈하기 | 의심하는 쪽 |
| 리스 | D 생활 | 빌려 쓰는 정수기 — 쓸 권리도, 갚을 의무도 장부에 | 진행 |
| 연결재무제표 | D 생활 | 엄마 가게와 아들 가게 사이 거래는 집안 전체로 보면 지운다 | 의심하는 쪽 |
| 재무비율 분석 | B 연구실 | 건강검진 수치 (한 수치만 보면 오진) | 의심하는 쪽 |
| 원가회계·손익분기 | B 연구실 | 실험 한 번에 드는 고정 장비비와 시약비 | 진행 |
| 감사 | B 연구실 | 봉인관이 실험 노트를 표본으로 골라 확인 | 의심하는 쪽 (주인공급) |
| 세무 기초 | D 생활 | 연말정산 영수증 상자 (세율·공제 수치는 기준일 필수) | 의심하는 쪽 |

생물 앵커(A)는 쓰지 않는다.

## P4. 사실 카드 추가 필드

| 필드 | 필수 | 예 |
|---|---|---|
| `기준 체계` | 회계 처리 문장마다 | K-IFRS / 일반기업회계기준 / US GAAP / 중소기업회계기준 |
| `기준서·조항` | 기준을 근거로 할 때 | K-IFRS 제1115호, 문단 번호(확인한 경우만) |
| `기준일·시행일` | 기준서·세법 | 자료가 기준으로 삼은 날, 시행일 |
| `개정 이력` | 대체된 기준을 언급할 때 | 옛 리스 기준(제1017호) → 제1116호로 대체 |
| `세법 연도` | 세율·공제 | 귀속 연도 |
| `예시 회사` | 사례 | 가상 회사임을 표시. 실제 기업 공시를 쓰면 공시일·출처(DART 등) |

기준서 번호를 확인하지 못했으면 번호를 쓰지 않고 "{주제}에 관한 기준"으로 쓴다. 문단 번호는 원문을 직접 확인한 경우에만 쓴다.

## P5. 상호작용 모듈 카탈로그

모든 회사·거래는 가상(예시값). 거래를 넣으면 **세 재무제표가 함께 바뀌는 것**을 보여 주는 것이 이 분야 시뮬레이션의 중심이다.

| 모듈 | 조작 | 그림 | 행동으로 보기 | 기대 결과·교훈 |
|---|---|---|---|---|
| 회계 등식 시소 | 거래 카드 끌어 넣기 | 시소 양쪽 막대 | 이사 상자 옮기기 | 어떤 거래든 양쪽이 같이 움직이거나, 한쪽 안에서 바뀐다. 시소는 늘 수평 |
| T계정·분개 | 거래 고르기 | 차변·대변 T계정, 시산표 | — | 차변 합 = 대변 합이 늘 성립. 맞지 않으면 빨간 경고 |
| 세 재무제표 연동 | 거래 카드 (외상 매출, 현금 회수, 설비 구입, 감가상각) | 재무상태표·손익계산서·현금흐름표 세 판 | 동네 빵집 하루 | 감가상각은 이익을 줄이지만 현금은 그대로, 설비 구입은 현금을 줄이지만 그해 비용은 일부만 |
| 흑자도산 | 외상 비율, 회수 기간 | 이익 누적선 vs 현금 잔액선 | 외상 손님만 가득한 빵집 | 이익은 플러스인데 현금이 바닥나는 달이 생긴다 |
| 감가상각 방법 비교 | 방법(정액·정률), 내용연수, 잔존가치 | 해마다 비용 막대 + 장부금액 선 | 노트북 닳기 | 취득원가 1,000, 잔존가치 100, 5년: 정액 해마다 180 / 정률(약 36.9%) 약 369 → 233 → 147 → 93 → 58. 합계는 둘 다 900 |
| 재고 원가흐름 | 방법(선입선출·평균), 매입 단가 상승률 | 우유 냉장고 칸 + 매출원가 막대 | 냉장고에서 꺼내기 | 100개 @10, 100개 @12를 사서 100개 @20에 팔면: 선입선출 매출원가 1,000·이익 1,000, 총평균 매출원가 1,100·이익 900. 값이 오를 때 선입선출 이익이 크게 나온다 |
| 수익인식 5단계 | 계약 조건(묶음 판매, 기간) | 계약 → 의무 → 가격 → 배분 → 인식 흐름 | 정기 배송 상자 | 돈을 미리 받아도 의무를 다한 만큼만 수익. **기준서 번호는 기준일 칩과 함께** |
| 손익분기점 | 고정비, 판매 단가, 단위 변동비 | 수익선·비용선 교차 | 실험 장비비와 시약비 | 고정비 3,000, 단가 5, 변동비 3이면 손익분기 1,500개 |
| 재무비율 | 재무제표 숫자 | 비율 계기판 여럿 | 건강검진표 | 한 비율만 좋아지게 바꾸면 다른 비율이 나빠지는 경우를 보여 줌 |
| 감사 표본 | 표본 크기, 오류율 | 전표 격자에서 표본 뽑기 | 봉인관이 노트 고르기 | 오류율이 낮으면 작은 표본으로는 못 찾을 수 있다 (통계 팩과 연결) |

## P6. 대결 질문 예

| 질문 | 초파리(의심) | 주판봇(확신) | 판정 기준 | 종류 (코어 6-4) | 결과 |
|---|---|---|---|---|---|
| 이익이 났으니 이번 달 월급은 문제없다? | 현금부터 확인 | 이익이 났으니 OK | 예시 회사의 월말 현금 | 계산으로 정해짐 | F |
| 값이 오르는 해, 이익이 더 크게 나오는 방법은? | 평균법 | 선입선출법 | 예시 거래의 이익 | **사실 판정** ("어느 쪽이 크게 나오나") | R — 단 "더 좋은 방법"이 아니라고 박사가 덧붙인다 |
| 첫해 비용이 더 큰 감가상각은? | 정액법 | 정률법 | 1년 차 비용 | 사실 판정 | R (판정 문장은 "첫해 비용은 정률이 크다") |
| 1년치 구독료를 받은 날 전부 수익? | 나눠서 인식 | 받은 날 전부 | 기준서 원칙 | 기준 안에서 정해짐 (관할 칩) | F |
| 대규모 할인 판매로 매출을 늘리면 이익도 늘까 | — | 매출이 늘면 이익도 | 공헌이익 | 조건에 따라 (단가와 변동비) | C |
| 어느 회계 정책을 택해야 하나 | — | — | — | 규범·정책 선택 | 대결로 만들지 않는다 (코어 6-4) |

회계 정책 선택 대결은 승자를 정해도 판정 문장을 "{조건}에서 {지표}는 {방법}이 크다"로만 쓰고, 표정은 무거운 패배 표정(`fly_cry`, `robo_cry`)을 쓰지 않는다.

## P7. 자주 틀리는 단정 (금지 목록)

| 틀린 단정 | 바른 표현 |
|---|---|
| "이익 = 현금" / "흑자면 돈이 있다" | "이익은 발생 기준, 현금은 실제 들어오고 나간 돈. 흑자인데 현금이 부족할 수 있다" |
| "수익 = 이익" | 회계의 수익(revenue)은 매출 등 들어온 가치, 이익은 수익에서 비용을 뺀 것 |
| "감가상각은 자산의 시장가치 하락을 잰다" | "취득원가를 쓰는 기간에 나누어 배분한다" |
| "충당금은 따로 모아 둔 돈이다" | "부채나 자산 차감으로 인식한 추정액이다. 현금을 따로 떼어 둔 것이 아니다" |
| "자본 = 회사가 가진 현금" | "자산에서 부채를 뺀 잔여 지분이다" |
| "재무상태표의 금액은 지금 팔면 받을 값이다" | 측정 기준(원가, 공정가치 등)이 항목마다 다르다 |
| "이 처리가 정답이다" (관할 없이) | "{기준 체계}에서는 ~" — 후입선출법처럼 기준 체계마다 허용 여부가 다른 처리가 있다(K-IFRS는 후입선출법을 허용하지 않는다) |
| 대체된 옛 기준을 현행처럼 | 시행일과 대체 관계를 적는다 (코어 10-6) |
| "회계 처리를 바꾸면 회사 가치가 바뀐다" | 현금흐름이 같으면 경제적 실질은 같다. 다만 세금·계약 조건을 통해 현금흐름이 달라질 수 있다 |
| 세율·공제 한도를 기준 연도 없이 | 귀속 연도를 적는다. 세무 판단은 전문가 확인 문구 |
| "감사의견 적정 = 회사가 건전하다" | "재무제표가 회계기준에 따라 중요한 부분에서 적정하게 작성되었다는 의견이다" |

세무·감사 주제 페이지는 바닥글에 "이 페이지는 교육용이며 세무·회계 자문이 아닙니다." 문구를 둔다.

## P9. 온톨로지 확장

| 항목 | 값 |
|---|---|
| 주로 쓰는 클래스 | `Account`, `Standard`, `Identity`, `Concept`, `Method`(원가흐름 가정, 감가상각 방법), `Metric`(재무비율), `Claim` |
| 주로 쓰는 관계 | `governedBy`(처리 → 기준서), `supersededBy`(옛 기준 → 새 기준), `appliesIn`(기준 → 관할), `partOf`(계정 → 재무제표 항목), `contrastsWith`(선입선출 ↔ 평균법) |
| 필수 필드 | `Standard`와 기준에 근거한 `Claim`에 `jurisdiction`, `asOf` |
| `family` 값 | `foundations`, `bookkeeping`, `statements`, `revenue`, `inventory`, `ppe`, `financial-instruments`, `leases`, `provisions`, `equity`, `income-tax`, `cash-flow`, `consolidation`, `analysis`, `cost`, `managerial`, `audit`, `tax`, `disclosure` |
| 외부 매핑 | IFRS Taxonomy 요소(`scheme: ifrs-taxonomy`), XBRL 공시 요소(`scheme: xbrl`), Wikidata. ID는 확인한 것만 |
| 분야를 넘는 개념 | 현재가치는 `econ`·`biz`, 표본추출은 `stats`와 같은 ID. 회계 '수익(revenue)'과 재무 '수익(return)'은 다른 ID(코어 19-5) |
