## P10. 뼈대 초안 v0.1 (`backbone_data.json`)

작성자 초안, 공식 분류 체계 아님. 이 표는 JSON에서 만든 요약이고 원본은 JSON이다.

| # | 영역 | level | 주제 |
|---|---|---|---|
| 1 | 데이터 모델링 | 1 | 개체-관계 모형(ERD), 정규화, 키와 제약조건 |
| 2 | 관계형 데이터베이스 | 1 | 관계 모형, SQL, 조인, 트랜잭션과 ACID |
| 3 | NoSQL과 벡터 DB | 3 | 문서·키-값 저장소, 벡터 데이터베이스, 그래프 데이터베이스 |
| 4 | 데이터 파이프라인 | 2 | ETL·ELT, 데이터 정제·결측치, 스프레드시트 자동화 |
| 5 | 데이터의 수치화 | 1 | 범주형 인코딩, 이미지를 배열로, 소리 신호의 수치화, 텍스트 벡터화 |
| 6 | 데이터 시각화 | 1 | 차트 고르기, 대시보드, 움직이는 시각화 |

선수 관계(영역): 데이터 모델링 → 관계형 데이터베이스 · 관계형 데이터베이스 → NoSQL과 벡터 DB · 관계형 데이터베이스 → 데이터 파이프라인 · 데이터의 수치화 → 데이터 시각화.
