# 분야 팩 · 생성형 AI (`genai`)

## P1. 분야 신호어 (코어 2-0-1에 더함)

| 강한 신호 (3점) | 보통 신호 (1점) |
|---|---|
| 확산 모델, 잠재 확산, 텍스트→이미지, 가이던스, 인페인팅, 샘플링 온도, 멀티모달, CLIP, 영상 생성, 음성 합성, 역렌더링, 딥페이크, 워터마크 | 그림 생성, 프롬프트, 스타일, 캐릭터 |

자주 함께 오는 보조 분야: 딥러닝(생성 모델), LLM(프롬프트), 그림(구조), AI 범죄(딥페이크).

- 저작권·초상권 판단을 단정하지 않는다 — 관할과 기준일, "법률 자문 아님"

## P9. 온톨로지 확장

| 항목 | 값 |
|---|---|
| 주로 쓰는 클래스 | `Method`, `Concept`, `Metric`(FID, CLIP 점수), `Dataset`, `Limitation`, `Claim` |
| 주로 쓰는 관계 | `prerequisiteOf`, `contrastsWith`(GAN ↔ 확산), `evaluatedBy`, `hasLimitation`, `addressedBy` |
| `family` 값 | `foundations`, `image-generation`, `video-audio`, `3d-generation`, `multimodal`, `creative-workflow`, `risks` |
| 외부 매핑 | ACM CCS, CSO, Wikidata |
| 분야를 넘는 개념 | 확산·오토인코더는 `ai` 생성 영역 주제를 그대로 쓴다(다리), 딥페이크는 `crime`과 다리 |

## P10. 뼈대 초안 v0.1 (`backbone_genai.json`)

작성자 초안, 공식 분류 체계 아님. 이 표는 JSON에서 만든 요약이고 원본은 JSON이다.

| # | 영역 | level | 주제 |
|---|---|---|---|
| 1 | 생성 모델의 원리 | 2 | 우도 기반 생성, 잠재 변수 모형, 샘플링과 온도, 생성 품질 평가 |
| 2 | 이미지 생성 | 3 | 텍스트→이미지, 잠재 확산, 조건과 가이던스, 이미지 편집·인페인팅, 캐릭터·스타일 일관성 |
| 3 | 영상·음성 생성 | 4 | 영상 생성, 음성 합성, 음악 생성 |
| 4 | 3D·월드 생성 | 4 | 3D 복원, 역렌더링, 월드 모델 |
| 5 | 멀티모달 | 3 | 시각-언어 모델, 이미지-텍스트 정렬(CLIP), 다중 입출력 생성 |
| 6 | 생성 AI 작업 흐름 | 2 | 이미지 프롬프트 작성, 사람이 고르는 반복 제작, 에셋 파이프라인 |
| 7 | 생성 AI의 위험과 권리 | 3 | 딥페이크, 저작권과 학습 데이터, 워터마크·출처 표시 |

선수 관계(영역): 생성 모델의 원리 → 이미지 생성 · 생성 모델의 원리 → 영상·음성 생성 · 생성 모델의 원리 → 3D·월드 생성 · 생성 모델의 원리 → 멀티모달 · 이미지 생성 → 생성 AI 작업 흐름 · 생성 모델의 원리 → 생성 AI의 위험과 권리.
