# 분야 팩 · 경영학 (`biz`)

## P1. 분야 신호어 (코어 2-0-1에 더함)

| 강한 신호 (3점) | 보통 신호 (1점) |
|---|---|
| 순현재가치(NPV), 내부수익률, 자본비용, 포지셔닝, 세분화·표적·포지셔닝(STP), 브랜드 자산, 고객생애가치, 재고 관리, 리드타임, 대기행렬, 동기 이론, 조직 문화, 변화 관리, 이해관계자, 지배구조 | 매출, 고객, 팀, 프로젝트, 성장 |

자주 함께 오는 보조 분야: 회계학(재무관리), 통계학(마케팅 조사, 품질관리), 경제학(산업조직), 인공지능(디지털 전환, 핀테크).

## P2. 짝 카드와 연결 상자

| 자리 | 이름 |
|---|---|
| 짝 카드 오른쪽 | "경영 이론으로는" (계산 주제면 "계산으로는") |
| 파란 연결 상자 | "회사에서는" — 이 개념이 회의, 보고서, 예산, 채용, 출시 결정에서 어떻게 쓰이는지 + 비유의 한계 |
| 빨간 연결 상자 | "현장에 옮기면" (공통) — 데이터 준비, 조직의 실행 장애, 측정 지표 |

## P3. 기본 앵커

| 주제 | 주 앵커 | 대응 예 | 초파리 캐릭터의 역할 |
|---|---|---|---|
| 경영 기초·조직 구조 | B 연구실 | 박사 연구실의 역할 분담(박사·조수·초파리·로봇) | 진행 |
| 경쟁 전략 | D 생활 | 같은 골목의 두 분식집이 다른 손님을 노리는 법 | 의심하는 쪽 ("그 틀이 결과를 예측해?") |
| 마케팅 (세분화·포지셔닝) | D 생활 | 학교 축제 부스: 누구에게 무엇을 팔까 | 의심하는 쪽 |
| 소비자 행동 | B 연구실 | 같은 상품을 다르게 진열했을 때 고르는 피험자 | 의심하는 쪽 |
| 가격 책정 | C 장부 | Money-Robo의 가격표 실험 (가상 상품) | 의심하는 쪽 |
| 운영관리·대기행렬 | D 현장 | 연구실 식당 배식 줄, 공장 검사 라인 | 진행 |
| 재고·공급망 | D 현장 | 축제 날 붕어빵 반죽을 얼마나 준비할까 (뉴스벤더) | 의심하는 쪽 |
| 품질관리 | D 현장 | 검사 라인의 관리도 | 진행 (통계 팩과 연결) |
| 재무관리·투자 결정 | C 장부 | Money-Robo의 투자 장부 (가상 사업, 실제 종목 금지) | 의심하는 쪽 |
| 위험과 분산 | C 장부 | 달걀을 여러 바구니에 (가상 자산) | 의심하는 쪽 |
| 인사·동기 | B 연구실 | 조수가 일할 맛 나는 연구실 | 진행 |
| 리더십 | B 연구실 | 박사의 연구실 운영 방식들 | 의심하는 쪽 (박사에게 묻는다) |
| 의사결정 과학 | B 연구실 | 실험 장비 구매 결정 나무 | 진행 |
| 디지털 전환·정보 시스템 | D 현장 | 손으로 쓰던 실험 노트를 시스템으로 옮기기 | 의심하는 쪽 |
| 창업·비즈니스 모델 | D 생활 | 연구실 1층 카페를 열기까지 | 의심하는 쪽 ("손님이 정말 와?") |
| 기업윤리·지배구조 | D 현장 + B | 심사위원 이해충돌, 회의록 공개 | 의심하는 쪽, 박사가 균형 |

**경영 분석 틀(5 Forces, SWOT, BCG 매트릭스 등)은 계산 모형이 아니다.** 틀을 시뮬레이션처럼 숫자를 넣어 결과를 "예측"하게 만들지 않는다. 틀은 "생각을 정리하는 칸"으로 보여 주고(카드 분류 모듈), 장점과 한계를 함께 적는다.

생물 앵커(A)는 쓰지 않는다.

## P4. 사실 카드 추가 필드

| 필드 | 쓰는 때 | 예 |
|---|---|---|
| `사례 종류` | 기업 사례 | 실제 기업(출처·시점 필수) / 가상 기업 / 교과서 사례 |
| `사례 시점` | 실제 기업 | "{연도} 당시". 지금도 그렇다고 쓰지 않는다 |
| `근거 수준` | 경영 이론의 효과 | 대규모 실증 / 사례 연구 / 실무자 경험 / 분석 틀(근거 아님) |
| `이론 출처` | 이론·틀 | 제안자·연도 (확인한 경우만) |

실제 기업 사례는 공개 자료로 확인한 사실만 쓰고, 그 회사의 성공·실패 원인을 하나로 단정하지 않는다.

## P5. 상호작용 모듈 카탈로그

모든 회사·상품·숫자는 가상(예시값).

| 모듈 | 조작 | 그림 | 행동으로 보기 | 기대 결과·교훈 |
|---|---|---|---|---|
| 순현재가치 vs 회수기간 | 할인율, 현금흐름 | 연도별 현금흐름 막대 + 할인된 막대 | Money-Robo의 투자 장부 | 투자 1,000, 3년간 매년 400: 회수기간 2.5년. 할인율 10%면 NPV 약 −5, 8%면 약 +31. 같은 사업도 자본비용에 따라 판단이 바뀐다 |
| 손익분기·공헌이익 | 고정비, 단가, 변동비 | 수익선·비용선 | 축제 부스 | 고정비 3,000, 단가 5, 변동비 3이면 1,500개 (회계 팩과 같은 예) |
| 뉴스벤더 (재고 결정) | 판매가, 원가, 남은 재고 처분가, 수요 분포 | 수요 분포 + 주문량 선 + 기대이익 곡선 | 붕어빵 반죽 준비 | 판매가 3,000, 원가 1,000, 처분가 0이면 임계비율 2/3, 수요 분포의 약 67% 지점만큼 주문 |
| 대기행렬 (리틀의 법칙) | 도착률, 처리 속도 | 줄 길이 애니메이션 + 평균 대기 시간 | 배식 줄 | 평균 대기 인원 = 도착률 × 평균 머무는 시간. 처리 속도가 도착률에 가까워지면 줄이 급격히 길어진다 |
| 가격과 수요 | 가격, 탄력성 | 매출 직사각형 | 가격표 실험 | 경제 팩 탄력성 모듈과 같은 계산, 결과는 탄력성에 따라 갈림 (C) |
| 고객생애가치 | 한 달 이익, 유지율, 할인율 | 남는 고객 수 감소 곡선 + 누적 가치 | 단골 손님 카드 | 유지율이 조금만 올라도 가치가 크게 오른다. **계산식이 교재마다 달라 어느 식인지 화면에 적는다** |
| 분산 투자 (가상 자산) | 자산 수, 상관계수 | 포트폴리오 변동성 곡선 | 바구니에 나눠 담은 달걀 | 상관이 낮을수록 변동성이 줄어든다. **실제 종목·수익률 금지, 투자 자문 아님 문구** |
| 생존 편향 | 망한 회사 보이기 켜기·끄기 | 성공 회사만 vs 전체 회사 점 | 사라지는 가게 카드 | 성공 사례만 보면 특정 특징이 성공 원인처럼 보인다 |
| A/B 테스트 | 표본 크기, 효과 | 두 전환율과 구간 | 두 축제 부스 | 표본이 작으면 차이가 우연일 수 있다 (통계 팩 모듈 재사용) |
| 결정 나무 | 확률, 보상 | 나무 그림 + 기대값 | 장비 구매 결정 | 기대값과 위험 선호가 결정을 바꾼다 |
| 분석 틀 카드 분류 | 사례 카드 끌어 넣기 | SWOT 네 칸 등 | 연구실 회의 | 같은 사실이 보는 사람에 따라 강점이 되기도 위협이 되기도 한다 (틀의 한계) |

| 질문 | 초파리(의심) | Money-Robo(확신) | 판정 기준 | 종류 (코어 6-4) | 결과 |
|---|---|---|---|---|---|
| 성공한 회사들 공통점을 따라 하면 성공할까 | 망한 회사부터 본다 | 성공 공식 그대로 | 전체 회사 중 그 특징의 성공률 | 정의 안에서 정해짐 (생존 편향) | F |
| 축제 날 반죽을 얼마나 준비할까 | 평균 수요만큼 | 넉넉히 많이 | 기대 이익 | 조건에 따라 (마진과 폐기 비용) | 예시 조건에서 계산, 조건을 바꾸면 C |

| 가격을 올리면 매출이 늘까 | 유지 | 인상 | 매출 | 조건에 따라 (탄력성) | C |
| 어떤 리더십이 가장 좋은가 / 어떤 전략이 이기나 | — | — | — | 논쟁·상황 의존 | 대결 금지 또는 C. 연구가 상황에 따라 엇갈린다고 쓴다 |

## P7. 자주 틀리는 단정 (금지 목록)

| 틀린 단정 | 바른 표현 |
|---|---|
| "성공한 기업의 공통점이 성공의 원인이다" | "생존 편향을 빼고, 비교 집단이 있어야 원인을 말할 수 있다" |
| "SWOT·5 Forces를 하면 답이 나온다" | "분석 틀은 생각을 정리하는 도구다. 결론은 데이터와 판단으로 정한다" |
| "{기업}은 {한 가지 이유}로 성공(실패)했다" | 여러 요인과 시점을 적고, 출처의 주장으로 쓴다 |
| "매출이 늘면 이익도 는다" | 공헌이익과 고정비에 따라 다르다 |
| "회수기간이 짧으면 좋은 투자다" | 화폐의 시간가치와 회수 이후 현금흐름을 함께 |
| "고객 만족이 높으면 매출이 오른다" | 관련은 있을 수 있으나 측정 방법과 인과를 따로 확인 |
| "분산 투자하면 손실이 없다" | "변동성을 줄일 수 있다. 손실이 없어지지는 않는다" |
| "{리더십 유형}이 언제나 최고다" | 상황 의존적이라는 연구 결과를 함께 |
| 실제 기업 사례를 시점 없이 현재형으로 | "{연도} 당시" |
| 경영서·실무서의 주장을 학술 근거처럼 | P4 `근거 수준`을 표시 |

재무·투자 주제 페이지는 코어 5-5의 "투자 자문 아님" 문구를 둔다.

## P9. 온톨로지 확장

| 항목 | 값 |
|---|---|
| 주로 쓰는 클래스 | `Concept`, `Theory`, `Framework`, `Method`(평가 방법: NPV, 회수기간), `Metric`, `Assumption`, `Claim`(실증 결과, 근거 수준 표시) |
| 주로 쓰는 관계 | `contrastsWith`(NPV ↔ 회수기간), `assumes`, `evaluatedBy`, `prerequisiteOf`, `supports` |
| 근거 수준 | `Claim`에 `lab.evidenceLevel`: `empirical-large` / `case-study` / `practitioner` / `framework` |
| `family` 값 | `foundations`, `strategy`, `marketing`, `consumer`, `pricing`, `operations`, `supply-chain`, `quality`, `finance`, `investment`, `risk`, `hr`, `leadership`, `decision`, `digital`, `entrepreneurship`, `ethics-governance`, `international` |
| 외부 매핑 | STW 경제 시소러스의 경영 부분(`scheme: stw`), Wikidata. 금융 개념은 FIBO(`scheme: fibo`). ID는 확인한 것만 |
| 분야를 넘는 개념 | 현재가치·손익분기는 `acct`·`econ`과, A/B 테스트·관리도는 `stats`와 같은 ID |
