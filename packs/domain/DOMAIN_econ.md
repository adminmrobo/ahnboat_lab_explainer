# 분야 팩 · 경제학 (`econ`)

## P1. 분야 신호어 (코어 2-0-1에 더함)

| 강한 신호 (3점) | 보통 신호 (1점) |
|---|---|
| 기회비용, 비교우위, 소비자잉여, 생산자잉여, 사중손실, 외부효과, 공공재, 독점, 과점, 내쉬균형, 총수요·총공급, 승수, 필립스 곡선, 기준금리, 환율, 경상수지, 잠재성장률, 효용극대화 | 소득, 물가, 세금, 정부, 무역, 성장 |

자주 함께 오는 보조 분야: 통계학(계량경제), 경영학(산업조직, 재무), 회계학(국민계정과 기업회계 비교).

## P2. 짝 카드와 연결 상자

| 자리 | 이름 |
|---|---|
| 짝 카드 오른쪽 | "모형에서는" |
| 파란 연결 상자 | "뉴스·정책으로 읽으면" — 이 개념이 금리 결정, 물가 기사, 세금 논쟁, 무역 뉴스에서 어떻게 쓰이는지. **한계 한 줄은 늘 "모형은 가정을 따른다"** |
| 빨간 연결 상자 | "현장에 옮기면" (공통) — 가계·기업의 실제 의사결정, 데이터의 기준일과 개정, 단위 |

## P3. 기본 앵커

시장·돈 이야기 자체가 경제학의 본론이므로, 앵커는 **시장이 아닌 장면**에서 고른다(코어 7-2 시험 4번).

| 주제 | 주 앵커 | 대응 예 | 초파리 캐릭터의 역할 |
|---|---|---|---|
| 희소성·기회비용 | D 생활 | 주말 하루를 공부와 아르바이트 중 무엇에 쓸까 | 의심하는 쪽 ("포기한 건 계산했어?") |
| 수요·공급·균형 | D 생활 | 축제 날 붕어빵 줄 길이와 가격표 | 의심하는 쪽 |
| 탄력성 | D 생활 | 소금 값과 극장표 값이 같은 비율로 오를 때 | 의심하는 쪽 |
| 소비자 선택 | D 생활 | 용돈으로 간식 장바구니 채우기 | 진행 |
| 생산·비용 | B 연구실 | 실험 조수를 한 명 더 쓸 때 늘어나는 실험 수 (한계생산) | 진행 |
| 시장 구조 | D 생활 | 동네에 빵집이 하나일 때와 열 개일 때 | 의심하는 쪽 |
| 게임이론 | B 연구실 | 두 연구원이 장비 예약을 동시에 고를 때 | 대결 장치와 바로 연결 |
| 외부효과·공공재 | D 생활 | 공동 냉장고, 아파트 놀이터 청소 당번 | 의심하는 쪽 |
| 국민소득 계정 | D 생활 | 마을 전체의 1년 생산 목록 (중간재는 두 번 세지 않기) | 의심하는 쪽 |
| 성장 | B 연구실 | 장비가 늘고 실험 기술이 좋아지는 연구실 | 진행 |
| 화폐·물가 | D 생활 | 놀이공원 토큰을 갑자기 두 배로 찍어 낼 때 | 의심하는 쪽 |
| 경기변동·총수요 | D 생활 | 손님이 줄면 다시 손님이 주는 동네 상점가 (연쇄) | 의심하는 쪽 |
| 통화정책 | D 생활 | 수도꼭지 밸브로 욕조 물 높이 조절 (시차가 있다) | 의심하는 쪽 |
| 국제무역 | D 생활 | 요리와 설거지를 나눠 맡는 두 룸메이트 (비교우위) | 진행 |
| 행동경제학 | B 연구실 | 같은 실험을 다르게 설명했을 때 답이 바뀌는 피험자 | 의심하는 쪽 (주인공급) |
| 자산 가격·금융 | C 매출 기록 | 주판봇의 매출 기록과 주판 (실제 종목·지수 금지) | 의심하는 쪽 |

생물 앵커(A)는 쓰지 않는다. "개미의 분업" 같은 생물 비유도 경제 개념과 일대일로 맞지 않으면 쓰지 않는다.

## P5. 상호작용 모듈 카탈로그

모든 비교정학 모듈은 "움직인 변수 / 고정한 변수"를 화면에 적는다(코어 9-9). 모든 수치는 예시값.

| 모듈 | 조작 | 그림 | 행동으로 보기 | 기대 결과·교훈 |
|---|---|---|---|---|
| 수요·공급 이동 | 소득, 원가, 기대 | 두 직선과 균형점 | 붕어빵 줄 길이 | 어느 곡선이 움직였는지와 곡선 위 이동을 구분 |
| 세금과 사중손실 | 세금 크기 t | 잉여 넓이 색칠 | — | 수요 P = 100 − Q, 공급 P = 20 + Q에서 균형 Q = 40, P = 60. 판매자에 t = 20이면 Q = 30, 소비자 70·판매자 50, 세수 600, 사중손실 100 |
| 가격 상한 | 상한 가격 | 초과수요 막대 | 줄이 길어지는 가게 | 위 예에서 상한 50이면 수요 50, 공급 30, 부족 20 |
| 탄력성과 매출 | 탄력성, 가격 인상률 | 매출 직사각형 넓이 | — | 가격 +10%일 때 탄력성 −2면 매출 약 −12%, −0.5면 약 +4.5% (근사) |
| 기회비용·비교우위 | 두 사람의 생산성 | 생산가능곡선 두 개 + 교역 후 점 | 룸메이트 분업 | 둘 다 특화하면 총생산이 늘 수 있다. 절대우위가 없어도 |
| 죄수의 딜레마 | 보수행렬 값, 반복 횟수 | 보수행렬 + 선택 기록 | 초파리와 주판봇이 직접 고름 | 한 번이면 둘 다 배신이 균형, 반복하면 협력 전략이 나을 수 있음 |
| 단리 vs 복리 | 이자율, 기간 | 두 성장 곡선 | 주판봇의 주판알 더미 | 100을 연 5%로 10년: 단리 150, 복리 약 162.89. 72의 법칙 근사 14.4년, 정확히는 약 14.2년 |
| 명목 vs 실질 | 명목 금리, 물가 상승률 | 두 막대 | — | 명목 5%, 물가 3%면 실질 약 1.94% (근사 2%) |
| 단순 승수 | 한계소비성향 | 지출이 퍼지는 단계 막대 | 상점가 연쇄 | 폐쇄경제·조세 없음 가정에서 MPC 0.8이면 승수 5. **가정을 화면에 적는다** |
| 국내총생산 세기 | 거래 카드 끌기 | 최종재 vs 중간재 상자 | 마을 생산 목록 | 중간재를 넣으면 두 번 세어진다 |
| 외부효과 | 피해 크기 | 사적 비용 vs 사회적 비용 곡선 | 공동 냉장고 | 시장 수량이 사회적 최적보다 많다 |
| 독점 vs 경쟁 | 기업 수 | 가격·수량·잉여 비교 | 빵집 하나 vs 열 개 | 독점은 수량이 적고 가격이 높다 (모형 가정 하에서) |
| 매몰비용 | 이미 쓴 돈, 앞으로의 이득 | 결정 나무 | 이미 산 영화표 | 결정은 앞으로의 비용·이득만으로 |
| 시계열 지표 읽기 | 기준(전기 대비/전년 동기 대비) | 같은 자료의 두 증가율 | — | 같은 데이터라도 기준에 따라 숫자가 달라 보인다. **실제 통계는 기준일·판차 칩** |

| 이자 5%, 물가 3%. 진짜 불어난 돈은? | 실질로 다시 계산 | 5% 늘었다 | 실질 구매력 | 정의 안에서 정해짐 | F |

| 정부 지출을 늘리면 경기가 좋아질까 | — | — | — | **논쟁 중** (경제 상황과 가정에 따라) | C로만, 두 견해 같은 분량 |

## P7. 자주 틀리는 단정 (금지 목록)

| 틀린 단정 | 바른 표현 |
|---|---|
| "국내총생산은 국민의 행복(후생)이다" | "시장에서 거래된 최종 생산의 가치다. 여가, 가사 노동, 분배, 환경은 따로 봐야 한다" |
| "합리적이란 이기적이라는 뜻이다" | "주어진 목표와 제약 안에서 일관되게 고른다는 뜻이다. 목표에 남을 돕는 것이 들어갈 수 있다" |
| "수요가 늘었다" (가격이 내려서 산 양이 늘었을 때) | "수요량이 늘었다" — 곡선 이동과 곡선 위 이동을 구분 |
| "돈을 찍으면 모두 부자가 된다" / "돈을 찍으면 반드시 그만큼 물가가 오른다" | 장단기, 경제 상황, 기대에 따라 다르다고 쓴다 |
| "무역은 한 나라가 이기고 다른 나라가 진다" | "모형에서는 양쪽 모두 이득을 볼 수 있다. 다만 나라 안에서 이득과 손해가 사람마다 다르게 나뉜다" |
| "명목 금리가 오르면 저축이 무조건 유리하다" | 실질 금리와 세금을 함께 |
| "경제학은 ~라고 증명했다" (논쟁 주제) | "{학파·연구}는 ~라고 본다. 반대 견해는 ~" (코어 6-4) |
| "모형이 단순하니 틀렸다" / "모형 결과가 곧 현실이다" | "모형은 가정을 따른다. 어떤 가정이 현실에 가까운지는 실증으로 본다" |
| "물가 상승률이 내렸다 = 물가가 내렸다" | "오르는 속도가 줄었다" |
| 기준일·단위 없는 거시 수치 | 코어 10-6 |
| 특정 정부·정당·정책을 평가하는 문장 | 정책의 경제학적 논점만, 찬반 근거를 같은 분량으로 |

## P9. 온톨로지 확장

| 항목 | 값 |
|---|---|
| 주로 쓰는 클래스 | `Theory`(모형), `Assumption`, `Concept`, `Indicator`, `Identity`(국민소득 항등식), `Claim`(실증 결과), `Question`(논쟁 질문) |
| 주로 쓰는 관계 | `assumes`, `measuredBy`(물가 → 소비자물가지수), `contrastsWith`(학파 대비, 방향 없이), `raises`, `supports`(실증 연구 → 주장) |
| 논쟁 표시 | 논쟁 중인 `Claim`은 `confidence: mid` 이하, `Question` 노드를 만들어 양쪽 `Claim`이 `raises`로 잇는다 |
| `family` 값 | `thinking`, `markets`, `consumer`, `producer`, `structure`, `games`, `welfare`, `labor`, `accounts`, `growth`, `money`, `cycles`, `monetary`, `fiscal`, `trade`, `intl-finance`, `behavioral`, `econometrics`, `finance` |
| 외부 매핑 | JEL 분류 코드(`scheme: jel`), STW 경제 시소러스(`scheme: stw`), Wikidata. ID는 확인한 것만 |
| 분야를 넘는 개념 | 회귀분석·도구변수·이중차분은 `stats`와, 현재가치·위험은 `biz`와 같은 ID |
