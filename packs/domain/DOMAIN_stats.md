# 분야 팩 · 통계학 (`stats`)

## P1. 분야 신호어 (코어 2-0-1에 더함)

| 강한 신호 (3점) | 보통 신호 (1점) |
|---|---|
| 불편추정량, 표준오차, 검정통계량, 유의수준, 검정력, 제1종·제2종 오류, 사전·사후분포, 중심극한정리, 대수의 법칙, 분산분석(ANOVA), 카이제곱, t분포, 층화추출, 가중치 보정, 부트스트랩 | 평균, 중앙값, 상관계수, 표본, 모집단, 그래프 |

자주 함께 오는 보조 분야: 경제학(계량경제), 인공지능(통계적 학습), 경영학(마케팅 조사, 품질관리).

## P3. 기본 앵커

| 주제 | 주 앵커 | 대응 예 | 초파리 캐릭터의 역할 |
|---|---|---|---|
| 기술통계 (평균·중앙값·분산) | D 생활 | 반 친구들 키 줄 세우기, 한 명의 억만장자가 들어온 카페의 평균 소득 | 의심하는 쪽 ("평균 말고 가운데는?") |

| 확률분포 | D 생활 | 버스 도착 간격(지수), 하루 전화 건수(포아송) | 의심하는 쪽 |
| 표본분포·중심극한정리 | B 연구실 | 같은 실험을 수백 번 되풀이한 실험 노트 더미 | 진행 |
| 추정·신뢰구간 | B 연구실 | 고리 던지기: 말뚝(모수)은 고정, 고리(구간)가 움직인다 | 의심하는 쪽 ("이번 고리가 걸렸는지는 몰라") |
| 가설검정·p값 | B 연구실 | 재판: 무죄 추정(귀무가설), 증거가 충분해야 유죄 | 의심하는 쪽 (주인공급) |
| 검정력·표본 크기 | B 연구실 | 어두운 방에서 손전등 밝기(표본 크기)와 찾는 물건 크기(효과 크기) | 의심하는 쪽 |
| 다중 비교 | B 연구실 | 스무 번 던진 다트 중 하나는 우연히 과녁에 | 의심하는 쪽 (주인공급) |
| 회귀분석 | D 생활 | 키와 몸무게 점들 사이로 긋는 한 줄 | 의심하는 쪽 ("그 선, 인과야?") |
| 범주형 자료·분할표 | D 생활 | 학교별·학과별 합격표 (심슨의 역설) | 의심하는 쪽 |
| 베이즈 추론 | D 생활 | 검사 양성 결과를 받은 날 (기저율) | 의심하는 쪽 |
| 표본조사·가중치 | D 현장 | 여론조사 콜센터, 응답자 카드 상자 | 의심하는 쪽 ("누가 전화를 안 받았지?") |
| 실험 설계·무작위화 | B 연구실 | 맹검 실험, 제비뽑기로 나눈 두 반 | 진행 |
| 시계열 | C 장부 | 매출 장부의 계절 패턴 (실제 종목 금지) | 의심하는 쪽 |
| 재표집 (부트스트랩) | B 연구실 | 같은 주머니에서 꺼냈다 넣기를 되풀이 | 진행 |
| 인과추론 | D 생활 | 우산을 든 사람이 많은 날 비가 오는 것 | 의심하는 쪽 |

생물 앵커(A)는 기본으로 쓰지 않는다. 초파리 실험 데이터(예: 행동 실험의 반복 측정)를 **예제 데이터로** 쓰는 것은 괜찮지만, 그것은 비유가 아니라 데이터이므로 7-4 강도표를 적용하지 않는다.

## P4. 사실 카드 추가 필드

| 필드 | 쓰는 때 | 예 |
|---|---|---|
| `표기 관례` | 공식을 쓸 때 | 표본분산 분모 n−1 / n, 로그는 자연로그 |
| `가정` | 검정·추정 결과를 쓸 때 | 독립, 정규성, 등분산 |
| `양측/단측`, `α` | 검정 결과 | 양측, α = 0.05 |
| `표본 설계` | 조사 자료 | 단순무작위 / 층화 / 군집, 응답률 |

교과서마다 기호와 분모 관례가 다르다. 자료의 관례를 그대로 따르고, 페이지 안에서 바꾸지 않는다.

## P5. 상호작용 모듈 카탈로그

모든 데이터는 시드 고정 난수, 이론값과 모의실험값을 나란히 둔다(코어 9-9).

| 모듈 | 조작 | 그림 | 행동으로 보기 | 기대 결과·교훈 |
|---|---|---|---|---|
| 평균 vs 중앙값 | 이상치 하나 추가·끌기 | 점 띠 + 평균·중앙값 표시선 | 카페 손님 카드에 억만장자 한 명 입장 | 평균은 크게 움직이고 중앙값은 거의 그대로 |
| 표본분포·중심극한정리 | 모집단 모양(균등·지수·두 봉우리), 표본 크기 n, 반복 수 | 모집단 히스토그램 → 표본평균 히스토그램 | 나르미가 표본 카드를 나름 | 지수분포(평균 1)에서 n = 30이면 표본평균의 표준편차 ≈ 1/√30 ≈ 0.18, 모양은 종 모양에 가까움 |
| 신뢰구간 적중률 | 신뢰수준, n, 반복 100회 | 구간 막대 100개, 모수를 놓친 막대는 빨강 | 고리 던지기 | 95% 구간이면 100개 중 대체로 90~99개가 적중(시드에 따라 다름). "이 구간이 맞을 확률 95%"가 아님을 설명 |
| 가설검정과 p값 | 효과 크기, n, α | 귀무분포 위 검정통계량 위치 + 꼬리 넓이 | 재판정 (봉인관이 판사) | 효과 0에서 반복하면 p < 0.05가 약 5% |
| 검정력 | 효과 크기 d, 집단별 n, α | 두 분포 겹침 + 검정력 막대 | — | 양측 α = 0.05, d = 0.5면 집단별 n ≈ 64에서 검정력 약 0.8 |
| 다중 비교 | 검정 수 k, 보정 방법(없음·본페로니) | 검정 k개의 p값 점 | 다트 던지기 | 효과가 없는데 20번 검정하면 하나 이상 '유의'가 나올 확률 1 − 0.95²⁰ ≈ 0.64 |
| 기저율 (베이즈) | 유병률, 민감도, 특이도 | 사람 1,000명 점 격자(넓이 그림) | 검사 결과 카드 | 유병률 1%, 민감도 99%, 특이도 95%면 양성일 때 실제 환자일 확률 약 17% |
| 심슨의 역설 | 집단 나누기 켜기·끄기 | 전체 막대 vs 집단별 막대 | 손님들이 두 학과로 나뉨 | 예시값: 학과마다 B 집단 합격률이 높은데 전체로는 A가 높을 수 있음 (A: 80/100, 4/20 → 70% / B: 18/20, 30/100 → 40%) |
| 회귀와 잔차 | 점 끌기, 이상치 | 산점도 + 최소제곱선 + 잔차 막대 | — | 지렛대가 큰 점 하나가 기울기를 크게 바꾼다 |
| 평균으로의 회귀 | 측정 오차 크기 | 1차 점수 vs 2차 점수 | 시험을 두 번 본 손님들 | 1차 상위권의 2차 평균은 내려옴, 처치 없이도 |
| 상관 ≠ 인과 | 숨은 변수 켜기 | 산점도 색을 숨은 변수로 | 우산과 비 | 숨은 변수를 고정하면 상관이 사라짐 |
| 부트스트랩 | 재표집 횟수 | 재표집 통계량 히스토그램 + 백분위 구간 | 주머니에서 꺼냈다 넣기 | 표본이 작으면 구간이 넓고 흔들림 |
| 표본 편향 | 응답률, 응답 성향 | 모집단 vs 응답자 분포 | 전화를 안 받는 손님들 | 표본을 키워도 편향은 줄지 않음 |

## P6. 대결 질문 예

| 질문 | 초파리(의심) | Money-Robo(확신) | 판정 기준 | 종류 (코어 6-4) | 결과 |
|---|---|---|---|---|---|
| 손님 소득의 대표값은? | 중앙값 | 평균 | 이상치 넣은 뒤 대다수 손님과의 차이 | 정의 안에서 정해짐 | F |
| 표본은 클수록 좋은가? | 작아도 무작위 표본 | 크지만 자발적 응답 표본 | 모집단 참값과의 오차 | 정의 안에서 정해짐 | F |
| 가설 스무 개를 시험해 하나가 유의 | 보정 후 판단 | "발견이다!" | 효과 0인 세계에서 거짓 발견률 | 정의 안에서 정해짐 | F |
| 표본이 적을 때 어느 추정이 나을까 | 단순한 모형 | 변수 많은 모형 | 새 표본 예측 오차 | 조건에 따라 (n이 크면 로봇) | C 또는 n에 따라 F/R |
| 큰 효과를 찾으려면 | 표본 늘리기 | 측정 정밀도 높이기 | 같은 비용에서 검정력 | 조건에 따라 | C |
| 효과가 뚜렷한 실험에서 n = 200 | 그래도 의심 | 충분 | 검정력 계산 | 정의 안에서 정해짐 | R |

시리즈 균형(코어 6-1)을 위해 R이 나오는 판을 일부러 둔다. 통계 페이지에서 초파리가 늘 이기면 "의심만 하면 된다"는 오개념이 생긴다.

## P7. 자주 틀리는 단정 (금지 목록)

| 틀린 단정 | 바른 표현 |
|---|---|
| "p값은 귀무가설이 참일 확률이다" | "귀무가설이 참이라고 할 때, 이만큼 또는 더 극단적인 결과가 나올 확률이다" |
| "95% 신뢰구간에 모수가 있을 확률이 95%다" | "같은 방법으로 구간을 반복해 만들면 그중 약 95%가 모수를 포함한다" (베이즈 신용구간과 구분) |
| "유의하지 않으면 효과가 없다" | "이 자료로는 효과를 확인하지 못했다" (검정력 함께) |
| "통계적으로 유의하면 중요하다" | 효과 크기와 실질적 의미를 따로 쓴다 |
| "상관이 있으면 인과가 있다" | "상관이 있다. 인과는 설계(무작위화 등)나 추가 가정이 있어야 말할 수 있다" |
| "표본이 크면 편향이 사라진다" | "무작위 오차는 줄지만 선택 편향은 그대로다" |
| "정규분포를 따르지 않으면 t검정을 못 쓴다" | 표본 크기와 검정의 강건성에 따라 다르다고 쓴다 |
| "R²가 높으면 좋은 모형이다" | 목적(설명·예측), 과적합, 잔차 진단을 함께 본다 |
| "평균은 늘 대표값이다" | 치우친 분포에서는 중앙값과 함께 |
| "확률 1%면 거의 안 일어난다" | 시행 횟수가 많으면 자주 일어난다 |
| 한 번의 연구 결과를 확정 사실처럼 | 재현 여부를 적는다 |

## P9. 온톨로지 확장
