꼬리표 조립기

완성된 HTML에 지식 색인과 꾸러미를 붙입니다. 파일은 이 브라우저 안에서만 처리하고 어디로도 보내지 않습니다. 본문은 바꾸지 않습니다.

1. 원본 HTML
여러 파일로 된 사이트라면 메인 HTML만 넣습니다. 이미지 경로는 그대로 둡니다.
2. AI가 만든 JSON 세 개
kg.json · refs.json · meta.json (이름에 kg, refs, meta가 들어가면 됩니다)
3. 스크립트 넣는 방식
연결 방식을 고르면 kgx.js도 함께 받아 같은 경로에 두세요.

파일을 넣으면 여기에 점검 결과가 나옵니다.
