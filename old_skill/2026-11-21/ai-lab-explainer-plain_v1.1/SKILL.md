# 연구실 확장 스킬북 — 비전공자판 (ai-lab-explainer-plain)

> version 1.1 · 기반: ai-lab-explainer(연구실 해설 기본 스킬) + ai-lab-extend(확장 스킬북) + concept-first-teaching(교수법 스킬, 기본 탑재) · language: ko
> **용어 규칙(최우선):** 개념을 차례로 쌓는 구성은 **개념정리**, 그 안의 한 덩어리는 **단계**, 표·양식의 한 자리는 **항목**, 비워 둘 곳은 **공란**, 입력 자리는 **상자**, 여러 주제를 하나로 꿰는 흐름은 **하나로 잇는·공통으로 흐르는**이라고만 쓴다. 오르내리는 기구에 빗댄 말, 뚫고 지나간다는 말, 구획을 세는 단위어는 페이지·문서·대사·주석·파일 이름·이미지 지시문 어디에도 쓰지 않는다. 기본 스킬이나 부속 파일에 그런 말이 남아 있어도 결과물에는 위 용어로 바꿔 쓴다.

> 기본 스킬의 모든 규칙(분야 확인, 사실 카드, 개념정리, 대결, 캐릭터 팩, 디자인 시스템, 지식 색인·꾸러미, 이미지 명세서)을 그대로 따른다. 이 문서는 **처음부터 비전공 독자를 위해 무엇을 다르게 하는지**만 적는다. 이미 만든 페이지를 고칠 때는 ai-lab-extend를 쓴다.

## 0. 언제 쓰나
- "AI(통계·경제)를 전혀 모르는 사람이 읽을 연구실 페이지", "비전공자용으로", "쉽게 풀어서 연구실 HTML로" 같은 요청.
- 교안 PDF를 그대로 옮기면 어려워질 자료(모델과 수식이 처음부터 나오는 장).

## 0-1. 교수법 스킬 기본 탑재 — 박사는 친절한 교육자 (v1.1)

이 스킬로 만드는 모든 페이지에는 concept-first-teaching의 교수법(7개 원칙 P1~P7, 개념 리듬 ①~⑧, AI 판단 코너, 자가 채점)이 **처음부터 적용된다.** 겉모양(캐릭터·흰 배경·레이아웃)은 이 스킬이, 무엇을 어떤 순서로 가르칠지는 교수법 스킬이 맡는다.

### 🚫 절대 금지 — 최우선 규칙
- **독자를 '수학·통계를 포기한 사람'으로 묶어 부르는 별칭(줄임말)은 어떤 캐릭터의 대사에도, 페이지의 어떤 글자에도 나오지 않는다.** 제목·부제·본문·말풍선·퀴즈·그림 alt·메타데이터(og·JSON-LD)·지식 색인·꾸러미·파일 이름·저장소 이름·외국어판 모두 포함.
- 그 별칭의 로마자 표기·번역어와 "수학을 포기한 사람", "수학 포기"처럼 독자를 포기한 사람으로 부르는 말도 쓰지 않는다.
- 독자는 "처음 오신 분", "여러분", "이 분야를 처음 접하는 분"으로 부른다.
- 7단계 검증에서 위 단어를 전체 검색해 **0건**이어야 완료다.

### 박사의 두 역할
박사는 캐릭터 팩의 성격·말투를 그대로 두고, 연구실 책임자 역할에 **친절한 교육자** 역할을 함께 맡는다.

| 자리 | 박사가 하는 일 |
|---|---|
| 단계 시작 | ① 상황 — 현장 질문 하나로 문을 연다("회사에서 이런 일이 생기면?") |
| 왜 이 모델 상자 앞 | ③ 말로 푼 원리 — 공식보다 "왜 이렇게 계산하는지"를 먼저 말한다(P1) |
| 조수 수식 상자 | 조수의 질문에 기호 하나씩, 읽는 법과 뜻을 먼저 답한다(P3). 손계산은 작은 숫자로 한 번 같이 해 본다(P2) |
| 단계 대화 | 주판봇의 성급한 확신을 "AI가 낸 결과"로 놓고, 박사가 "가정이 맞을까? 숫자가 그럴듯한가?"를 묻게 해 확인 습관을 연습시킨다(P6, AI 판단 코너) |
| 큰 그림·단계 사이 | 앞 개념 → 이 개념 → 다음 개념의 위치를 한 줄로 짚는다(P4). 필요한 선수 개념은 "30초 복습" 상자로 |
| 풀이 끝 | ⑦ 해석 문장 — "이 숫자는 업무에서 이런 뜻"으로 마무리(P5) |
| 막히기 쉬운 곳 | "여기서 한 번 멈춰도 괜찮아요", "처음엔 다들 여기서 오래 봅니다" 같은 안심 신호를 준다(P7) |

박사 대사 규칙
- 쓰지 않는다: "쉽죠?", "당연히", "기초인데", "이 정도는", 겁주는 말, 독자 수준을 낮게 보는 말.
- 단순화했으면 박사가 "여기서는 단순하게 봤어요"라고 밝힌다.
- 교육자 대사도 캐릭터 대본(4단계)에 함께 쓰고, 표정 키는 SPRITE에 싣는다.

## 1. 첫 질문 (한 번에)
기본 스킬의 분야 확인(2-0)에 더해 함께 묻는다.
1. 주 독자 한 줄 (기본값: 그 분야를 처음 접하는 직장인).
2. 원자료에서 틀린 곳이 있으면 어떻게 표기할지 (기본값: 저자 확인 뒤 "바꾼다").
3. 저자 바닥글 표기와 소개 사이트 주소.
4. 시험 주간 등 빈 주차를 연습(문제풀이)으로 채울지.

## 2. 작업 순서 (기본 스킬 0~9단계에 끼우는 것)
- **1단계 사실 카드**: 카드마다 "독자가 막힐 단어"와 "원자료와 다른 값"을 따로 표시한다. 다른 값은 검산해 확정하고 "바꾼다" 문장을 미리 써 둔다.
- **2단계 개념정리**: 단계마다 "왜 이 모델이 필요해졌나"(앞 단계의 한계)를 한 줄로 적는다. 그 줄이 3장의 「왜 이 모델을 쓰나」가 된다. 개념정리는 앞 단계의 한계가 다음 단계의 이유가 되게 잇는다.
- **2단계 보탬 — 독자 진단**: 교수법 스킬 2절로 독자 유형을 정한다(정하지 않으면 혼합형). 진단 이름은 작업 메모에만 쓰고 페이지에는 쓰지 않는다.
- **4단계 캐릭터 대본**: 히어로·대결·아웃트로 대사에 더해, 단계마다 실험 앞 대화 2~3줄과 수식 상자의 조수 질문·코멘트를 함께 쓴다. 박사의 교육자 대사(0-1)도 이때 단계마다 쓴다.
- **6단계 HTML**: 3장의 블록을 처음부터 넣는다. 문구는 데이터 파일(plain·abbr·easy·talk)에 모으고 빌드로 끼운다.
- **7단계 검증**: 4장 문장 규칙 검사 + 숫자 검산 + 390·1280px 화면 점검 + 교수법 기준표 자가 채점(P1~P7, 2점 미만 항목은 고침) + 금지어 전체 검색 0건.
- **9단계 페르소나 평가**: 독자 쪽 페르소나에 무게를 둔다(입문 독자, 그 독자의 상사, 숫자에 강한 실무자, 성인 학습자, 원자료 저자, 분야 전문가).

## 3. 페이지 구조 (기본 스킬 4-1·4-3에 더함)

페이지
1. 표지 → 히어로 → **처음 오신 분께 — 이 페이지를 3줄로**(무엇을 / 왜 중요한가 / 업무에서는, "코드·수식을 몰라도 됩니다", 접는 영어 약어 풀이) → 등장인물 → 왜 → 큰 그림 → 레벨 단계 → 대결 → 정리 → 아웃트로 → 지식 색인 → 꾸러미 → 바닥글.
2. 바닥글: `글 · <저자> (<소개 사이트>) · <소속>`.

레벨 단계 하나
1. 단계 제목 + 꼬리표 (코드 대신 "방법: …", "설정: …", "일상: …")
2. 모델·수식 단계이면 두 상자를 나란히:
    - 왼쪽 **왜 이 모델(방법)을 쓰나** — 문제 상황 → 앞 방법의 한계 → 해법, 「쉽게 말하면」 비유 한 줄
    - 오른쪽 **수학 수식을 어려워하는 조수가 대신 물어봅니다** — 조수 질문(놀란 표정) → 학교 수학으로 보면(교과 단원) → 식 조각 표 → 숫자로 한 번 해 보기(검산한 값) → 조수 코멘트(이해한 표정)
3. 일상으로 치면 | ○○에서는 (기본 스킬, 단 4장 문장 규칙으로)
4. **단계 대화** 2~3줄 (박사 질문 · 주판봇 성급한 확신 · 초파리 의심과 "이걸 눌러 봐" · 조수 보고), 실험 패널 바로 앞
5. 실험 패널, 풀이, 이 단계의 한계 (기본 스킬)
6. **교안의 파이썬 코드로 보면 (몰라도 됩니다)** 접기 상자 — 코드가 있는 단계만, 코드 한 줄 + 뜻 한 줄
7. 확인 퀴즈 (기본 스킬)

화면 밀도: 단계 간격 88px(모바일 64), 줄 간격 1.8, 상자 안쪽 여백 20px 안팎, 풀이 줄 사이 10px. 수식·왜 상자는 860px 아래에서 한 줄로 쌓는다.

## 4. 문장 규칙
1. 동작 먼저, 전문용어는 괄호로.
2. 이름 나열 대신 ① ② ③ 번호로 하나씩.
3. 기호(ρ σ α p)는 처음 나올 때 뜻을 앞에.
4. 본문에 코드·함수 이름·배열 모양·인자 이름 금지. 접기 상자로.
5. 숫자는 업무 말로("평균 25g 빗나감").
6. 원자료와 다른 값은 "원자료의 A를 이 페이지에서는 B로 바꿉니다".
7. 수식 상자 제목·본문에 "중·고등학생 눈높이" 같은 표현을 쓰지 않는다.
8. 문장 25~60자, 한 단락 세 문장 안팎.

## 6. 연습(문제풀이) 페이지 (선택)
시험 주간 등 빈 자리는 "연습"으로 채운다(번호 표기는 시리즈와 같게). 1부 원자료 연습문제 원문(즉시 정답·해설, 해당 주차 링크), 2부 주차마다 업무 장면 계산·사례 문제 1개(입력 채점·허용 오차, 단계별 풀이, 초파리의 흔한 실수, 업무에서는 한 줄, 숫자는 예시값이라고 밝힘), 주차별 점수(70% 미만은 해설로 안내, 저장하지 않음). 앞뒤 주차 링크를 연습 페이지로 잇는다.

## 6-1. 마지막 장 — 실전 연습장 (기본 탑재)
여러 장으로 된 시리즈·묶음에는 마지막 장으로 **실전 연습장**을 둔다. 배운 것을 가상 사업장(공장·가게·보험사·거래소 등)에서 직접 운영해 보는 시뮬레이터 동적 대시보드다.
- **위치·연결**: `practice/index.html` 단독 파일. 연구실 목차와 교과서 목차의 맨 끝에 「마지막 장 · 실전 연습장」으로 잇는다.
- **사업장 고르기**: 분야의 핵심 장마다 하나씩, 3~5개를 탭으로 둔다. 미시경제학 예: 공장(비용 최소화·이윤 극대화) · 가게(매출 꼭대기와 이윤 꼭대기·세금 부담·사중손실) · 보험사(확실성등가·역선택·정보의 가치) · 거래소(초과수요·시장청산·가격조정). 다른 분야는 그 분야의 현장(예: 배터리 라인, 병원, 은행)으로 바꾼다.
- **장면 하나의 구성**: 상황 설명 상자 → 조작판(초록 = 시장 환경 조건, 파랑 = 내 결정) → 성적표(핵심 수치 4개, 좋음/나쁨 색) → 실시간 그래프 2개(구조 그림 1 + 결정별 성과 곡선 1, 내 선택과 최적점 표시) → 캐릭터 4명 대사(상태에 따라 바뀜: 박사 판정·조수 수치 보고·초파리 의심·주판봇 성급한 확신) → 미션 3개(최적 찾기 / 함정·반례 관찰 / 조건을 바꿔도 결론이 유지되는지 확인, 허용 오차로 자동 판정, 학생이 조작하기 전에는 통과 표시 안 함) → 「배운 곳 다시 보기」 연구실·장 링크.
- **마무리 상자**: 여러 장면이 함께 묻는 질문 한 단락 + 모형의 한계와 「숫자는 교육용 예시, 경영·투자 권고 아님」.
- **모양·동작**: 흰 배경, 캐릭터는 기존 픽셀아트 팩 재사용, 외부 라이브러리 없는 SVG 그래프, 주소 끝 `#탭이름`으로 장면 바로 열기, 자동 재생은 모션 감소 설정에서 단계 이동으로, 기록은 현재 탭에만.
- **검사**: 장면마다 미션 정답 조작을 스크립트로 흉내 내 판정이 바뀌는지 확인하고, 최적값은 공식으로 검산한다.

## 7. 그림 (기본 스킬 18장에 더함)
- 처음부터 그림 전체 목록(새로 그릴 것 / 표지에서 자를 것 / 캐릭터 팩 재사용)과 만드는 순서대로 모은 프롬프트 파일을 함께 낸다.
- 생성 도구로 넘길 때는 요청 꾸러미 zip: 캐릭터 기본 그림 4장, 요청문(하나 = 대화 하나, 3~5장씩, 같은 비율끼리), 저장 이름 체크리스트. 목차 표지를 먼저 받아 그림체를 확인한 뒤 나머지에 참고 그림으로 함께 올린다.
- 아웃트로 표정은 대결 결과와 맞아야 한다. 틀리면 기존 그림 + 캐릭터 저장소의 표정 그림을 첨부해 "표정만 편집"으로 다시 요청한다.
- 반영: 표지 1600×900, 장면 1200×800 WebP 내장(한 편 600KB 이하), 목차 썸네일·공유 미리보기는 표지에서 잘라 별도 폴더에, 모든 페이지에 og:image.

## 8. 완료 기준
- 모든 모델·수식 단계에 왜/조수 수식 상자, 모든 단계에 대화, 본문 코드 0.
- 모든 "숫자로 한 번 해 보기"·연습 정답 검산 완료.
- 390·1280px 가로 넘침 0, 콘솔 오류 0, 빈 캐릭터 그림 0.
- 페르소나 평가에서 입문 독자 점수가 전문가 점수와 1점 이상 벌어지지 않을 것.
- 교수법 기준표 15점 이상(21점 만점), 모든 단계에 박사의 교육자 대사(상황 질문·해석 문장), 페이지마다 AI 판단 코너 1개 이상.
- 독자를 포기한 사람으로 부르는 별칭 및 같은 뜻의 말(로마자·번역어 포함) 0건 — 대사·본문·메타데이터·파일 이름·외국어판 전부.
- 여러 장 묶음이면 마지막 장 실전 연습장(6-1)이 목차에 연결되어 있고, 모든 미션 판정이 스크립트 검사를 통과할 것.
